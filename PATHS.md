# Paths and recommended skills

Founder Jam runs as one track with four paths. The day follows four stages: Understand, Focus, Build, Validate. During Focus, each founder picks a path with their sherpa. The path decides which skills to lean on. It does not lock anyone in, and any founder can borrow a skill from another path.

The four paths match the focus areas on the Founder Jam application:

| Path | `path` value | You pick it when |
|------|--------------|------------------|
| Product and positioning | `product-positioning` | You're unsure what to build or how to describe it |
| GTM and growth | `gtm-growth` | You have something to sell and need a repeatable way to reach customers |
| Sales | `sales` | You have an offer and need conversations, calls, and closes |
| Ops and automation | `ops-automation` | Manual work is eating your week and you want to automate it |

## How to start

1. Run `founder-setup` first. It asks whether a sherpa is with you, captures your startup context, suggests a path, and prints a FOUNDER JAM HANDOFF block.
2. Paste that block at the start of each later skill. Every skill prints an updated block when it finishes, so the latest one always goes into the next skill.
3. Everyone finishes with `validation-planner` (your 2 days / 2 weeks / 2 months commitments) and `pitch-builder` (your share-out).

## Skills by path and stage

Skills in bold are the core of the path. The rest are good additions if you have time.

### Product and positioning

| Stage | Skills |
|-------|--------|
| Understand | **`battle-card-builder`**, `market-analyzer` |
| Focus | **`hypothesis-engine`**, `icp-definer` |
| Build | **`prototype-launcher`**, `offer-architect` (if the question is packaging or price) |
| Validate | **`validation-planner`**, **`pitch-builder`**, `landing-page-auditor` (if the prototype is a page) |

### GTM and growth

| Stage | Skills |

### Sales

| Stage | Skills |
|-------|--------|
| Understand | `battle-card-builder`, `market-analyzer` |
| Focus | **`icp-definer`**, `hypothesis-engine` |
| Build | **`outbound-composer`** (third-party, CC0), **`offer-architect`**, `show-rate-optimizer`, `nurture-engine` |
| Validate | **`validation-planner`**, **`pitch-builder`**, `testimonial-collector`, `case-study-generator` |

### Ops and automation

| Stage | Skills |
|-------|--------|
| Understand | `market-analyzer` |
| Focus | **`hypothesis-engine`** (use it to pick the one process worth automating) |
| Build | **`growth-builder`** (its automation sub-activity covers lead enrichment and support), `prototype-launcher` (to prototype the workflow) |
| Validate | **`validation-planner`**, **`pitch-builder`** |

This path has the thinnest coverage today. If your process isn't lead enrichment or support, use `prototype-launcher` to sketch the workflow and let your sherpa help you scope it.

## Notes

- `page-launcher` is Claude Code only because it publishes with shell commands. If you work in claude.ai or Claude desktop, ask Claude to build the page as an artifact and publish or share that instead. The skill explains how.
- `outbound-composer` and `page-launcher` were written by Scott Murtaugh of GP Automations. They stay under CC0 1.0 and are third-party material in this pack.
- The sherpa skills are for the people guiding a cohort. Founders don't need them.
